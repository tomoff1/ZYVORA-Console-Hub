# ZYVORA 0.1.0

Première version Windows native gratuite : explorateur FTP, envoi et téléchargement, édition de petits fichiers texte, payloads TCP/HTTP, catalogue avec SHA-256, index local PKG/homebrew, copies FTP et diagnostic à règles.

Un transfert FTP aller-retour avec empreintes identiques a été validé sur une PS5 déclarée 13.60. Les tests locaux couvrent les variantes EPSV/MLSD et PASV/LIST. Le petit compagnon ELF ZYVORA a aussi démarré via le loader sur cette console ; aucune certification générale des payloads tiers n'est revendiquée.

Installation PKG distante, cheats/mods, jaquettes, extensions, mises à jour automatiques et application PS5 installable ne sont pas disponibles. Voir STATUS.md et le rapport de validation avant utilisation.

Le compagnon ELF expérimental est distribué séparément avec son source et sa licence GPL-3.0-or-later. Les composants publics SDK sont sous leurs licences d'origine : [source SDK v0.44](https://github.com/ps5-payload-dev/sdk/tree/v0.44), [archive source correspondante](https://github.com/ps5-payload-dev/sdk/archive/refs/tags/v0.44.zip). ZYVORA Windows est sous MIT. Le compagnon n'est pas un PKG et n'offre pas d'interface graphique PS5.
