# ZYVORA 0.1.0

Première version Windows native gratuite : explorateur FTP, envoi et téléchargement, édition de petits fichiers texte, payloads TCP/HTTP, catalogue avec SHA-256, index local PKG/homebrew, copies FTP et diagnostic à règles.

Un transfert FTP aller-retour avec empreintes identiques a été validé sur une PS5 déclarée 13.60. Les tests locaux couvrent les variantes EPSV/MLSD et PASV/LIST. Le chargement de payloads n'a pas été certifié sur la console.

Installation PKG distante, cheats/mods, jaquettes, extensions, mises à jour automatiques et application PS5 installable ne sont pas disponibles. Voir STATUS.md et le rapport de validation avant utilisation.
